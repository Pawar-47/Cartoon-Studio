# Cartoon Studio

An original, local-first Urdu 3D cartoon production studio. The project is developed and released from this GitHub repository.

## Project status

Initial repository bootstrap is in progress. The first milestone establishes the requirements registry, architecture/research records, a lightweight web application shell, automated tests, and Windows CI packaging. No production-ready cartoon generation capability is claimed yet.

## Development principles

- Read and trace the complete project specification before implementation.
- Research and evaluate existing open-source projects before building components.
- Preserve third-party licenses and asset provenance.
- Use GitHub Actions for repeatable validation and Windows build artifacts.
- Render actual episodes locally; GitHub Actions is not treated as a free GPU render farm.
- Optimize for Intel Core i3-5005U, Intel HD Graphics 5500, 8 GB RAM, and SSD.
