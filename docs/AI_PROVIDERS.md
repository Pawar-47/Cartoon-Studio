# AI Provider Research Register

No AI provider is currently integrated. Do not store API keys in source code or commit secrets.

Evaluate FreeMilk by Milq, ChatGPT Free, Gemini, Claude, Microsoft Copilot, Perplexity and other suitable services.

For each provider record:
- Official product and terms URL.
- Current free allowance and reset/refill schedule.
- Pakistan availability.
- Model and task quality.
- Coding/research/file capabilities.
- Official API and integration support.
- Automation restrictions.
- Privacy and data retention.
- Fallback/manual handoff path.
- Date last verified.

Do not assume an app has a public API because its web interface exists. Use official APIs and supported integrations only. Never bypass quotas, extract private endpoints, automate prohibited UI flows or store provider credentials in Git.

The core project must remain functional if all external AI services are unavailable.
