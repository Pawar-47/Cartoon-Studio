# Open-Source Research — Blender-First Direction

## Research objective
Find reusable Blender Python tools/add-ons and open-source foundations for high-quality original characters, environments and props, plus Godot production integration. Research must result in implementation decisions and tested tools, not endless candidate lists.

## Required domains
- Blender Python API automation and headless execution.
- Character modeling, topology, stylized faces, rigging, skinning, facial morphs, hair and clothing.
- Procedural architecture, buildings, roads, terrain, vegetation, interiors and world kits.
- Vehicles, furniture, props and reusable geometry/material libraries.
- Blender-to-GLB export and Godot 4.7.2 import.
- Recipe/version/provenance and asset management.
- Browser job orchestration and FFmpeg production.

## Research rules
Inspect source, documentation, recent commits, issue activity, tests, exact code license and separate asset/model/data licenses. Do not rely on stars alone. Do not copy GPL/AGPL code without explicit approval. MPFB is excluded as product foundation. Blender itself is GPL-3.0; use as external authoring tool and review any redistribution.

## Existing research retained
Prior Ara, Ekza, Godot, Blender add-on, Quaternius, Kenney, TTS and animation research remains useful as dated background. Earlier recommendation of Ara as primary editor and Godot-only asset workflow is superseded. Re-evaluate only where it materially helps the current Blender-centered architecture.

## Next research batch
Inspect candidate Blender add-ons and scripts for reusable, permissively licensed functionality in character geometry/rigging and procedural environments. Prefer modular techniques and implement only after a bounded proof on the project's Blender version.
