# P1.4 Installer Decision — Current Amendment

Historical installer decisions remain applicable to the existing Windows app where still accurate. Blender is not bundled as a required installed-app runtime. The installed app must launch without Blender present. Blender authoring is a separately configured worker/toolchain; future optional bundling requires explicit size, compatibility and GPL-3.0 distribution review.

Godot 4.7.2 remains the production worker and retains its exact pinned runtime/license handling. Preserve user project data across upgrade/uninstall.
